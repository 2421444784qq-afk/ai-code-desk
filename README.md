# AI Code Desk · v0.7.2

本地 Windows AI 编程客户端：兼容 OpenAI Chat Completions 接口，自带 API Key；支持流式对话（可停止生成）、文件上传与解析（TXT/MD/PY/DOCX/PDF/PNG/JPG/XLSX/PPTX）、打开项目文件夹、按文件名读取文件、在完全权限下由 Agent 调用 PowerShell、后台长任务与产物验收、文件修改预览（应用/撤销），以及 Word / Excel / PowerPoint / Visio 的结构读取、PDF 预览与副本编辑。

## 启动

在 PowerShell 中运行：

```powershell
cd D:\GPT-Workspace\AI-Code-Desk
npm.cmd install
npm.cmd start
```

第一次启动填入 API 地址（例如供应商提供的 `https://.../v1`）、模型 ID 和 API Key，再点“保存连接”。密钥由 Windows 的 Electron safeStorage 加密后存在应用用户数据目录，界面不回显。只有调用所配置的 API 时才发送密钥。模型调用产生的费用由对应供应商收取。

界面左侧显示会话与工作区文件树；右上角“连接设置”可以修改 API 配置，对话、文件修改、任务和 Office 通过顶部标签切换。工作区支持添加多个项目并随时切换（＋ 添加，悬停项目行点 ✕ 从列表移除，磁盘文件不会被删除）；每个工作区各自记住上次打开的状态。会话支持删除（悬停会话行点 ✕）。打开的工作区会在下次启动时恢复；会话记录保存在本机。打开项目文件夹后，在聊天里提到文件名（如 `function.txt`）会自动读取并附上文件内容；同名文件请写相对路径或先选中。聊天栏会显示实际读取并发送的文件。勾选“始终附带当前文件”可在一般聊天中附带当前所选文件。选中文本文件，填写修改要求，先检查预览，再决定是否应用。应用时自动备份原文件，可撤销最近一次由本应用完成的修改；如果文件被外部软件改变，应用会拒绝覆盖。不要将密钥粘贴到聊天或项目文件里。

## 流式输出与停止生成

对话默认使用流式输出：回答逐字显示，无需等待整段生成。生成过程中发送按钮会变成“■ 停止”按钮，点击后中断本次请求，已生成的部分保留在会话中。工具调用（完全权限下）也走流式通道，命令执行过程实时显示在会话里。接口超时按“120 秒无新内容”计算，而不是整个回答的总时长；不支持流式的接口会回退按一次性响应解析。文件修改建议（生成修改预览）仍采用非流式请求。

## 文件上传与解析

输入框左侧的 📎 按钮支持上传文件，解析结果随下一条消息一起发送给模型（可一次附加多个，悬停标签点 ✕ 移除）：

- **TXT / MD / PY** 等文本：直接读取（UTF-8，自动回退 GBK）
- **DOCX**：提取正文段落与表格
- **XLSX**：提取各工作表名称与前 200 行数据（公式单元格显示缓存值）
- **PPTX**：提取每页幻灯片文本并统计内嵌图片数
- **PDF**：提取文本（支持 ToUnicode 与 UTF-8/Identity 编码）；扫描件（文本极少）暂不支持 OCR，会给出提示
- **PNG / JPG** 等图片：转为 base64 放进 `image_url` 内容块发送（OpenAI 多模态格式），在对话中提到图片文件名或点击文件树中的图片也会自动随附（需要所配置的模型支持图片输入）

限制：文件不超过 10 MB、图片不超过 4 MB、提取文本不超过 20 万字符、一次最多 4 张图片。所有解析都在本机完成，无需外部服务。

## 权限选择

对话输入框右下角提供三档模式，设置会在本机保存。**仅可查看**可以读取文件和聊天，不能生成或应用修改；**工作区内修改**可以预览并确认修改已打开工作区中的文件；**完全权限**允许 Agent 在聊天中调用 Windows PowerShell，运行命令或用 `Start-Process` 启动本机软件；命令和结果会显示在会话里，并由模型读取后继续处理。短命令最多运行 30 秒、最多返回约 12 KB 输出；长任务在后台运行，日志和状态持久保存在本机。每轮最多四次工具调用。文件修改页仍需预览确认。终端命令本身可以访问工作区外的文件与程序，因此只在你愿意让当前任务实际操作电脑时选用。模型服务必须支持 Chat Completions 的工具调用接口。

## 长任务与结果验收

切换到“完全权限”后，在聊天中说明命令、工作目录与预期产物，例如“在项目中运行训练脚本，预期产物是 output\model.pt；启动后告诉我任务 ID”。Agent 会调用 start_task；“任务”标签可查看最近任务、末尾日志、停止任务和验收产物。长任务进程独立于窗口，关闭再打开客户端仍可查询。后台任务使用应用自带运行时启动（通过 ELECTRON_RUN_AS_NODE），不依赖系统中单独安装的 Node.js。任务最多同时运行三个，单路日志上限 5 MB，页面每三秒刷新状态。

“验收产物”要求进程以退出码 0 完成，且每个预期文件存在、非空、修改时间晚于任务启动。该检查不判断模型训练质量、图片内容、程序运行正确性；这些需按任务另做验证。没有提供预期产物时不会标记验收通过。任务记录保存在 Electron 的用户数据目录，异常结束可能显示“状态未知”，日志可供排查。

## Office 适配：结构读取、PDF 预览与副本编辑

打开工作区后点击左侧 Office 文件，切换到“Office”标签即可查看结构或导出 PDF；预览保存在应用数据目录，不覆盖原文件。在“完全权限”对话中，Agent 可调用 office_inspect、office_export_pdf、office_add_flow_slide，以及新增的 word_edit、excel_edit、visio_edit。

**副本编辑（原件始终不变）**——编辑结果写入应用数据目录中的副本，并同时导出 PDF 预览，可一键打开检查：

- **Word**：追加一级标题（# 开头）、段落和表格（每行用 | 分隔单元格），或由 Agent 按 spec 执行整篇替换（replace）、追加标题/段落/表格；验收检查返回段落数、表格数与“追加内容是否写回成功”。
- **Excel**：按“工作表 + 单元格”写入数值或公式（= 开头），写入后强制重算并回读每个单元格，自动报告 # 开头的公式错误单元格（如 #DIV/0!）。
- **PowerPoint**：在演示文稿副本中新增一页可编辑的流程图，并导出 PDF 预览。
- **Visio**：在副本中新增可编辑流程图页（开始/结束椭圆、步骤矩形、带箭头连线），并导出 PDF 预览。注意：本机 Visio 若未激活（“产品激活失败”），会拒绝保存 .vsdx，此时应用自动把副本保存为旧版 .vsd 并给出提示；激活 Visio 后恢复正常保存 .vsdx。

导出成功仅证明文件能由本机 Office 打开并生成 PDF；内容美观、分页、字体、图表与流程图连线仍需人工打开预览检查。Office 自动化在登录的 Windows 桌面会话运行，可能被软件弹窗阻塞，遇到此情况可在 Office 窗口中处理后重试。已在本机 16 页 PowerPoint 上验证结构读取、PDF 导出与流程图页；Word / Excel / Visio 的编辑与导出已用本机样本回归。

## 打包

```powershell
cd D:\GPT-Workspace\AI-Code-Desk
npm.cmd run dist
```

产物输出到 `dist\`：NSIS 安装包（可选安装目录、创建桌面快捷方式）与便携版（免安装）。打包配置见 package.json 的 `build` 字段；Office 脚本（*.ps1）与后台任务 worker 通过 `asarUnpack` 解包，保证 PowerShell 与后台进程能读取。首次打包需要联网下载打包工具链，网络慢时可用镜像：

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npm.cmd run dist
```

未购买代码签名证书时，Windows SmartScreen 会提示“未知发布者”；正式商用建议购买证书签名（electron-builder 的 `win.certificateFile` 配置），并可用 electron-updater 配合 HTTPS 静态服务器实现自动更新。

## 当前边界

单文件、200 KB 内 UTF-8 文本；每次仅保留一项待应用预览和一次可直接撤销的修改。模型须按要求返回完整文件；未遵守格式时拒绝应用。差异预览使用带上下文的逐行补丁格式。API 必须兼容 `POST /chat/completions`；支持 SSE 流式响应（不支持流式时自动回退）。暂不支持多文件批量修改。上传解析为纯文本提取，扫描版 PDF 的 OCR 与图片内容提取依赖模型视觉能力。Office 编辑为结构级基础验收，视觉质量需人工确认。

开发版（`npm start`）与打包版共用 `%APPDATA%\AI Code Desk` 数据目录（首次启动自动迁移旧数据），会话、工作区、任务记录跨版本保留。

使用前可运行 `npm.cmd run check` 检查 JavaScript 语法，`npm.cmd test` 运行测试。
